# 演示脚本

## 准备

1. 启动后端：

   ```powershell
   uvicorn app:app --reload --host 127.0.0.1 --port 8000
   ```

2. 打开浏览器：

   ```text
   http://127.0.0.1:8000
   ```

## 演示流程

### 第一步：首次任务

输入：

```text
整理一份微服务架构设计文档
```

讲解点：

- 规划 Agent 将任务拆分为背景、功能、关键技术、测试、总结。
- 执行 Agent 生成协作结果。
- 检查 Agent 检查结果是否完整。
- 系统将任务经验写入共享记忆。

### 第二步：相似任务

输入：

```text
帮我整理微服务架构文档目录
```

讲解点：

- 系统通过关键词和相似度匹配命中共享记忆。
- 复用上一次任务的子任务结构和经验。
- 页面显示“命中共享记忆”。
- 实验指标显示步骤数量减少。

### 第三步：分工任务

输入：

```text
制定一次前后端开发分工方案
```

讲解点：

- 系统可以根据不同任务类型生成不同子任务。
- 共享记忆库中会沉淀新的任务经验。

## 答辩口径

本项目不接入真实大模型，而是用规则模拟 Agent 行为。这样做的目的是突出系统机制本身，包括通信、状态传递、共享记忆和可视化。后续可以把规划、执行、检查三个规则模块替换为真实大模型调用。
