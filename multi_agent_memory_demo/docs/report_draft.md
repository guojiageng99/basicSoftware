# 大作业报告草稿

题目：面向课程任务协作场景的多智能体低开销通信与共享记忆原型系统

## 1 背景问题

随着智能体技术在办公自动化、软件开发辅助、知识管理等场景中的应用增多，单一智能体已经难以覆盖复杂任务中的规划、执行、检查和经验复用需求。多智能体协作可以将复杂任务拆分给不同角色处理，但也带来了新的系统问题：智能体之间需要频繁通信，任务状态需要在多个角色之间同步，历史经验如果不能沉淀和复用，就会导致相似任务重复处理。

在课程任务协作场景中，这类问题非常典型。例如完成一份大作业报告时，需要先分析题目要求，再拆分报告结构，随后生成内容并检查是否完整。如果每次遇到相似任务都重新拆解和执行，会增加重复沟通成本。针对这一问题，本项目设计并实现一个多智能体协作通信与共享记忆原型系统，用规则模拟三个智能体的协作流程，并通过共享记忆机制验证经验复用对通信开销和处理步骤的降低效果。

## 2 系统功能

系统包含规划 Agent、执行 Agent、检查 Agent 三类角色。用户输入任务后，规划 Agent 负责识别任务类型并拆分子任务；执行 Agent 根据子任务生成执行结果；检查 Agent 负责检查结果是否覆盖任务要求，并输出检查结论。

系统提供四个核心功能模块：

1. 消息通信模块：记录智能体之间的每次通信，包括发送者、接收者、消息内容、消息类型和时间。
2. 状态管理模块：维护每个 Agent 的状态，包括 idle、working、done、failed，便于在页面中展示任务流转。
3. 共享记忆模块：使用 SQLite 保存历史任务、子任务、执行结果和经验总结。
4. 可视化界面：展示任务输入、Agent 状态、通信日志、共享记忆命中情况和实验指标。

## 3 关键技术

### 3.1 消息队列与通信记录

系统使用轻量级消息记录机制模拟智能体之间的通信。每条消息包含 sender、receiver、kind、content、time 等字段。通过消息日志可以回溯一次任务从用户提交到规划、执行、检查、写入记忆的全过程。

### 3.2 Agent 状态机

每个 Agent 使用统一状态模型表示运行过程。状态从 idle 进入 working，任务完成后进入 done，如果检查不通过则进入 failed。状态机使系统运行过程更加透明，也方便答辩演示时展示多智能体协作链路。

### 3.3 共享记忆存储

系统使用 SQLite 存储共享记忆。记忆条目包含任务描述、任务关键词、子任务列表、执行结果、经验总结、命中次数和更新时间。SQLite 部署简单、跨平台、无需独立数据库服务，适合作为课程原型系统的轻量级本地存储方案。

### 3.4 记忆命中机制

系统对任务文本进行关键词提取，并通过 Jaccard 相似度判断当前任务是否与历史任务相似。当相似度超过阈值时，系统认为命中共享记忆，复用历史子任务和经验，从而跳过完整的任务拆解流程。该机制能够直观体现共享记忆对重复任务处理的优化作用。

## 4 国产基础软件应用情况

本项目面向国产基础软件生态中的智能体协作场景，重点关注操作系统上层智能应用的任务协作、状态传递和经验复用机制。系统采用 Python、FastAPI、SQLite 和 Web 前端技术实现，具备跨平台运行能力，可在 Windows 和 Linux 环境中部署。

从国产基础软件课程角度看，本项目关注的是智能体系统在操作系统应用层的基础支撑能力：低开销通信、状态可观测、共享记忆持久化和可复用接口设计。后续如果迁移到国产 Linux 发行版，可将当前本地 SQLite 存储扩展为系统服务，将消息通信机制扩展为进程间通信或 D-Bus 接口，将共享记忆模块作为桌面智能助手或系统 Agent 的基础组件。

## 5 测试分析

系统设计了两类测试场景。第一类为首次任务处理，系统需要完成任务拆解、执行、检查和记忆写入。第二类为相似任务处理，系统首先检索共享记忆，如果命中历史任务，则复用子任务和经验。

测试示例：

- 首次任务：生成一份课程大作业报告提纲。
- 相似任务：帮我生成课程大作业报告目录。

测试结果表明，在相似任务命中共享记忆后，系统可以减少重复的拆解和执行步骤，消息数量和估算耗时均有所下降。该结果说明共享记忆机制能够提升多智能体协作中的经验复用能力。

## 6 总结

本项目完成了一个可运行、可演示的多智能体协作通信与共享记忆原型系统。系统通过规划 Agent、执行 Agent、检查 Agent 模拟多角色协作，通过消息日志展示低开销通信过程，通过 SQLite 共享记忆实现历史经验沉淀，并通过相似任务对比实验验证共享记忆的复用价值。

项目仍有进一步扩展空间。例如可以接入真实大模型 API，使 Agent 具备更强的自然语言理解能力；可以引入更复杂的向量检索算法，提高记忆命中准确率；也可以将共享记忆模块封装为系统服务，为更多应用提供统一的智能体经验复用能力。
