# 两人组任务分工

项目题目：面向课程任务协作场景的多智能体低开销通信与共享记忆原型系统

## 郭嘉庚（组长）

负责后端、整体架构和报告主线。

具体任务：

- 设计系统架构：规划 Agent、执行 Agent、检查 Agent、消息通信模块、共享记忆模块。
- 实现 FastAPI 后端接口，包括任务提交、共享记忆查询、运行记录查询。
- 实现 Agent 调度逻辑：任务拆解、子任务执行、结果检查、记忆写入与复用。
- 实现 SQLite 共享记忆库，保存历史任务、子任务、执行结果和经验。
- 完成对比实验：无共享记忆与启用共享记忆的消息数量、步骤数量、估算耗时对比。
- 撰写报告中的背景问题、系统设计、关键技术、测试分析。
- 答辩时主讲技术路线、系统架构、共享记忆机制和实验结论。

AI 工具使用建议：

- 生成或优化 FastAPI 接口代码。
- 生成 Agent 类设计和 SQLite 表结构。
- 辅助撰写报告技术章节。
- 生成测试用例和演示数据。

## 黄振明（组员）

负责前端展示、PPT 和演示材料。

具体任务：

- 设计 Web 页面布局，包括任务输入、Agent 状态、消息日志、共享记忆、实验指标。
- 实现前端页面与后端 API 对接。
- 整理演示流程：首次运行、相似任务命中记忆、对比实验结果。
- 制作 PPT：背景问题、系统功能、关键技术、国产基础软件应用情况、总结。
- 整理截图和录屏材料。
- 答辩时主讲系统功能、页面演示、测试结果展示和总结。

AI 工具使用建议：

- 生成 HTML/CSS/JS 页面。
- 生成 PPT 每页文案。
- 辅助整理演示脚本。
- 辅助撰写报告中的系统功能和总结部分。

## 统一口径

- 本项目不接入真实大模型，Agent 行为采用规则模拟。
- 项目重点是多智能体之间的通信机制、状态传递机制和共享记忆复用机制。
- 共享记忆的价值通过对比实验体现：相似任务命中历史经验后，步骤数量和消息数量减少。
