# 答辩 PPT 大纲

## 1 背景问题

- 多智能体协作可以拆分复杂任务，但会带来通信开销和状态同步问题。
- 相似任务如果不能复用历史经验，会造成重复拆解和重复执行。
- 本项目面向课程任务协作场景，设计低开销通信、状态传递和共享记忆机制。

## 2 系统功能

- 任务输入：用户输入课程相关任务。
- 规划 Agent：拆分任务。
- 执行 Agent：完成子任务。
- 检查 Agent：检查结果完整性。
- 共享记忆：保存历史任务和经验。
- 可视化界面：展示状态、消息、记忆和实验指标。

## 3 关键技术

- 消息通信：记录 sender、receiver、kind、content、time。
- 状态机：idle、working、done、failed。
- SQLite 共享记忆：保存任务、子任务、结果、经验、命中次数。
- 记忆命中：关键词提取 + Jaccard 相似度。
- 对比实验：无共享记忆 vs 启用共享记忆。

## 4 国产基础软件应用情况

- 系统面向国产基础软件生态中的智能体应用场景。
- 使用 Python、FastAPI、SQLite、Web 技术实现可迁移原型。
- 后续可迁移到国产 Linux 环境，扩展为系统服务、D-Bus 接口或桌面智能助手组件。

## 5 总结

- 已实现三个 Agent 的协作流程。
- 已实现消息通信、状态展示、共享记忆和可视化演示。
- 相似任务命中共享记忆后，处理步骤和消息数量减少。
- 后续可接入真实大模型和向量数据库。

## 6 课程感受与建议

- 通过项目理解了国产基础软件不仅包含操作系统内核，也包含支撑上层智能应用的基础机制。
- 多智能体系统需要关注通信、状态、存储和可观测性。
- 建议课程后续增加更多可运行的小型系统案例。
